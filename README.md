# OKKI 商机盘点与固定格式总结报告技能

对 OKKI/小满 CRM 商机做全量盘点，输出「左侧目录 + 图表 + 筛选 + 跳转」固定格式 HTML 总结报告，支持管理 / 业务双视角。

## 在线下载
- 一键安装包（含 SKILL.md + 脱敏示例）：见本仓库 Releases，或下载 `OKKI商机盘点与固定格式报告skill.zip`。

## 压缩包内容
- `SKILL.md` —— 技能核心文件（触发条件、角色选择、数据查询、固定版式、交付门禁）
- `README.md` —— 安装与使用说明
- `examples/示例_OKKI商机总结报告.html` —— 脱敏示例报告

## 安装
解压后放入 Agent 的 skills 目录，或通过 Accio Work skill 系统导入（frontmatter name = `okki-opportunity-summary-report-fixed`）。
