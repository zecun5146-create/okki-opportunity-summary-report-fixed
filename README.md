# OKKI 商机盘点与固定格式总结报告技能

对 OKKI/小满 CRM 商机做全量盘点，输出「左侧目录 + 图表 + 筛选 + 跳转」固定格式 HTML 总结报告，管理/业务双视角。

## 一键安装

```bash
# Windows
git clone https://github.com/zecun5146-create/okki-opportunity-summary-report-fixed.git && python okki-opportunity-summary-report-fixed\install.py

# macOS
git clone https://github.com/zecun5146-create/okki-opportunity-summary-report-fixed.git && python3 okki-opportunity-summary-report-fixed/install.py
```

或双击 `安装-Windows双击我.bat`（Win）/ `安装-苹果Mac双击我.command`（Mac）。

## 内容
- `okki-opportunity-summary-report-fixed/` —— 技能目录（SKILL.md + 脱敏示例）
- `install.py` —— 跨平台安装脚本
